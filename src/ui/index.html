安卓安装与离线使用指南

本系统为跨平台离线应用（PWA）+ 原生混合架构，前端零依赖、数据不上传，提供三种使用方式：

方法一：安卓手机直接安装（推荐）

  1. 用手机浏览器（Chrome / Edge / 系统浏览器）打开本页；
  2. 点击浏览器菜单（右上角三点），选择「添加到主屏幕」或「安装应用」；
  3. 手机桌面即生成「肘边备急」独立图标，全屏秒开，断网离线时算费与红线功能照常可用。

方法二：编译独立 Android APK

原生封装工程位于项目 android/ 目录，已内置完整 WebView 外壳：

  • 执行 gradlew assembleRelease 输出标准 .apk；
  • 支持 Android 8.0 至 15 各品牌手机与平板。

方法三：电脑端双击即用

直接双击 dist/index.html，任意浏览器打开即用，零服务器、零网络请求，门诊数据完全本地留存。
