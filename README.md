## 🌟 核心功能清单

### 1. 五大重点城市最新医保政策库
- **四川成都**：门诊共济保障机制，单颗常规种植全流程医疗服务最高调控限价 4400 元，基层门诊报销 60%~70%，支持家庭共济个账。
- **广东广州**：普通门诊“选点就医”制度，基层一类定点门诊统筹报销高达 80%~85%，月度额度与年度额度联动管理。
- **广东深圳**：医保一档/二档体系，社康及一级以下定点门诊 0 起付线直接报销 75%~80%，年统筹额度挂钩在岗社平工资（超万元）。
- **上海市**：门急诊“自负段”制度（在职 1000~1500元 / 退休 700元），起付后一级门诊统筹比例 75%~90%，统筹段上不封顶。
- **重庆市**：门诊共济低起付线（在职 100元 / 退休 50元），基层报销比例 60%~70%，种植调控上限 4300 元。

### 2. 口腔全科目医保收费标准库
- **检查影像**：X线摄影成像（012301010010000）、口腔曲面体层成像·全景片（012301010011100）、牙片（012301010020000）、口腔颌面锥形束CT·CBCT（012301020011100）—— 来自**放射检查类**立项指南（医保价采函〔2024〕233号）；支持「全景片 / 牙片 / CBCT / X光 / 根尖片」等口语叫法直接检索。
- **牙体牙髓**：前牙/双尖牙/磨牙显微根管治疗术、复合树脂美学充填术、玻璃离子水门汀充填术。
- **牙周科**：全口牙周龈上洁治术（超声波洁牙）、深层龈下刮治术与根面平整术。
- **口腔外科**：复杂阻生齿拔除术（骨埋伏/近中水平阻生）、常规后牙拔除术、简单牙拔除术。
- **集采种植**：单颗常规种植全流程调控服务费、国家集采种植体耗材包（零差率）、全瓷牙冠集采竞价包。
- **美容自费（高危红线区）**：成人隐形正畸矫治、冷光美白等（严禁串换医保统筹）。
- **医保耗材**：碧蓝麻（复方阿替卡因）、胶原蛋白止血海绵等。

### 3. 单笔税负估算（多税务模式 · 自由调参）
> ⚠️ 这一节是**开单时的税负估算**，不是申报依据 —— 增值税按申报期、所得税按年度计算。正式报税用功能 12。

- **模式1：纯医疗服务免税（法定免税）**：应税收入占比 0，增值税与附加均为 0，所得税按小微 5% 估算。
- **模式2：小规模纳税人（混营外售）**：应税部分按 **1%** 征收率（2026—2027 年 3% 减按 1%）、附加 6%（六税两费减半）、所得税 5%。
- **模式3：一般纳税人（连锁机构）**：应税货物按 13%、附加 12%（不减半）、所得税 25%（小微条件下实际 5%）。
- **模式4：个体工商户/个人独资**：缴**经营所得**个税（五级超额累进 5%~35%），非固定比例税率。
- **模式5：自定义税务模式**：财务可自由输入各税率与**应税收入占比**，即时看税后净利润与综合税负率。
- 🔑 **免税/应税分离**：医疗服务收入免征增值税，只有耗材/商品/非医疗美容部分计税。
  原实现把全部收入按一个税率计税，会显著多缴；新版本按「应税收入占比」拆开算。

### 4. 医保飞行检查红线实时预警引擎
- 🔴 **分解拆套收费拦截**：如“根管治疗术”并开“开髓引流术”或“牙髓失活术”立即致命红线拦截；
- 🔴 **重复缝合分解拦截**：如“复杂阻生齿拔除术”并收“软组织切开缝合术”立即一票否决；
- 🔴 **生活美容套刷统筹拦截**：正畸矫治、牙齿美白等纯美容项目严禁列入医保统筹或串换名目；
- 🔴 **国家集采超限价拦截**：单颗种植医疗服务费超越当地限价（成都4400/广深4320/沪渝4300）自动报警；
- 🔴 **集采耗材加成拦截**：集采耗材违背零差率加价销售自动预警；
- ⚠️ **超频次过度诊疗拦截**：洁牙单次大于1或超过年限额、单日重复全景片摄影实时预警。

### 5. 三大最优收费筹划方案矩阵
- **方案一：医保统筹最惠方案 (患者自付最低)**：在统筹额度充足时，最大化使用甲乙类合规项目报销，降低患者当期支付阻力；
- **方案二：品质与长效疗效平衡方案 (临床推荐)**：基础手术走医保统筹，高端冠部修复走合法自费或家庭共济个账；
- **方案三：零风险合规净化方案**：一键剔除检测到的拆套违规项，消除医保飞行检查处罚与信用降级风险。

### 6. 知情同意书自动匹配、检索与输出
- **自动输出**：处方里每加入一个项目，系统立即按治疗类别自动匹配应签署的知情同意书——
  选「根管预备费/冲洗费/充填费」自动带出**根管治疗知情同意书**，选「阻生牙拔除费」自动带出**阻生牙拔除术知情同意书**（高风险），
  任何有创操作同时自动附加**局部麻醉知情同意书**。高风险文书自动排在前面。
- **手动检索**：文书页内置 22 份知情同意书库，可按「根管 / 拔牙 / 种植 / 正畸 / 美白 / 洗牙」等关键词实时检索，点击卡片即可加入或移除。
- **一键全部加入**：把当前处方匹配到的文书一次性加入清单。
- **抬头信息带入**：填写患者姓名、性别、年龄、病历号、患牙位、机构名称后，自动写入每份文书的抬头与项目清单表。
- **三种输出方式**：`生成并打印全部`（A4 排版，一份文书一页，页眉页脚与签署区完整）、`预览全文`、`导出 HTML / TXT`（导出 HTML 为单文件自包含，可直接存档或转发）。
- **规范依据**：《医疗纠纷预防和处理条例》第十三条（实施手术、特殊检查、特殊治疗前应取得书面同意），
  每份文书含「诊断告知 / 治疗方案 / 风险与并发症 / 可替代方案 / 费用与医保说明 / 注意事项 / 患者声明 / 四方签署区」，并按门诊病历要求注明不少于 15 年归档说明。
- **合规提示内置**：114 版「牙体开髓引流费仅限牙髓急症应急处置」「龈上洁治费为丙类自费」「基本物耗不得另收」等红线口径已写入对应文书，避免告知与收费口径打架。

### 7. 项目详情卡（对齐官方原表全部 7 列）
点任意项目卡片的「详情」即可展开完整条目，字段与《口腔类医疗服务价格项目》官方表逐列对应：
**项目编码 · 项目名称 · 支付类别 · 计价单位 · 三级/二级/一级三档政府指导价（自动高亮本院级别）· 服务产出 · 价格构成 · 除外内容 · 计价说明 · 风险与限制提示**，
并附「医保属性说明」（甲类全额纳统 / 乙类先行自付 X% 后纳统 / 丙类全额自费）。弹层底部可直接「＋ 加入处方」，无需退出详情。

### 8. 医保门诊病历（按处方自动起草 · 医师补齐）
- **自动草稿**：处方一确定，系统按项目所属分类自动拼出「主诉 / 现病史 / 既往史与过敏史 / 口腔检查 / 辅助检查 / 诊断 / 治疗处置 / 医嘱」八段草稿，患牙位与项目名自动代入。
- **医师补齐**：每段都是可编辑文本，医生改过的段落会标记「已修改」，后续处方变动**不会覆盖**医生改写的文字。
- **患者信息复用**：姓名 / 性别 / 年龄 / 病历号 / 患牙位与知情同意书**共用同一份数据**，一处填写两处同步，不必重复录入。
- **输出方式**：`生成并打印病历`（A4，含医师签名与日期栏）、`预览全文`、`导出 HTML / TXT`。
- **规范依据**：《病历书写基本规范》（卫医政发〔2010〕11 号）与《医疗机构病历管理规定》，文书内注明不少于 15 年归档说明与「草稿须经医师核对签名生效」声明。

### 9. 搜索栏（关键词覆盖全部详情字段）
- 搜索范围覆盖 **项目名称 / 别名 / 编码 / 服务产出 / 价格构成 / 除外内容 / 计价说明 / 计价单位**，
  例：搜「矫治器」能命中 29 条「除外内容含矫治器」的矫治类项目；搜「CT」能命中 CBCT 而非仅按编码。

- 输入框内嵌一键清除；无结果时给推荐关键词，点一下直接出结果。

- **★ 自动结论卡（v1.3）**：报税页第一屏只回答三个问题 —— **交多少、什么时候交、会不会漏**。
  例如「2026 年第 4 季度 预计应缴税费 ¥7.90 ／ 申报截止 2027-01-15（还剩 90 天）／
  本期应税销售额 ¥135.15 未达起征点，增值税与附加都不用交；所得税仍需按期申报」。
  临近截止 7 天内转橙色、逾期转红色。
- **四种纳税人身份**：小规模企业 / 一般纳税人 / 个体工商户 / 个人独资，各自套用正确的税种与税率结构。
  不确定时保持默认即可（绝大多数口腔门诊是小规模纳税人）。
- **收入台账**：按日记录「医疗服务（免税）/ 耗材商品（应税）/ 非医疗美容（应税）/ 成本费用」，
  自动按申报期（**按月**或**按季**，一经选择会计年度内不得变更）汇总。
- **申报表填报底稿**：直接映射《增值税及附加税费申报表（小规模纳税人适用）》栏次，
  **数字可照着抄进电子税务局**：
  - 第 9 栏 免税销售额 = 10+11+12 ｜ 第 10 栏 小微企业免税销售额（企业填）
  - **第 11 栏 未达起征点销售额（个体户填，企业不填）**
  - **第 12 栏 其他免税销售额 —— 医疗服务免税填这里，不是 10/11 栏**
  - 第 15 栏 按 3% 计的应纳税额 ｜ **第 16 栏 减征额（减按 1% 的 2% 差额）** ｜ 第 20 栏 = 15−16
  - 第 22 栏 本期应补（退）税额 ｜ 第 23~25 栏 城建税 / 教育费附加 / 地方教育附加
- **真实口径计算**（不是把税率再调一遍）：
  - 起征点判定**只看应税销售额**——医疗免税收入不计入月 10 万 / 季 30 万基数；
  - 小规模减按 1% 走申报表真实逻辑：**按 3% 算应纳税额，再填 2% 减征额**，直接按 1% 算会对不上表；
  - 附加税费以**实际缴纳的增值税**为计税依据，增值税为 0 则附加为 0；六税两费减半；城建税分市区 7% / 县镇 5% / 其他 1%；
  - 小微企业所得税 300 万临界点（超 1 元即整体失格，全额 25%）；
  - 个体户**经营所得五级超额累进 + 200 万以内减半**（按累计分段计算，不是 2% 定额）；
  - 一般纳税人销项(13%/6%) − 进项 + 进项转出，并提示免税项目对应进项须转出。
- **税务风险自检**：技耗分离未分别核算（FATAL）、种植/修复打包收费未拆耗材（FATAL）、
  超政府指导价、免税项目开专票、进项未转出、小微临界点、起征点误把医保结算额算进去。
- **申报与缴款日历**：按月/按季生成全年申报节点，季度截止日为**季末次月 15 日**（Q1→4-15、Q4→次年 1-15），
  含企业所得税汇缴（次年 5-31）与经营所得汇缴（次年 3-31），遇周末自动顺延。
- **导出报税底稿**：`.txt`，含收入构成、税额、逐栏填报数、风险清单与政策口径，可直接交财务或税务师。

## 🚀 安装与使用方式

### 途径 0：直接在线使用（免安装）
- **GitHub Pages**：<https://drdentist-hub.github.io/dental-insurance-calc/>
- 手机浏览器打开后可「添加到主屏幕」，按 PWA 离线使用。

### 途径 A：电脑端双击即用（零配置免安装）
- 直接在电脑上双击 `dist/index.html` 即可在任意浏览器中秒开运行；
- 也可以双击 `start.bat`，启动局域网共享服务器。

### 途径 B：安卓手机/平板直接安装（PWA 离线原生体验）
1. 电脑双击 `start.bat` 或运行 `python run_app.py`；
2. 手机连接同一 WiFi，在手机浏览器中输入提示的局域网网址（例如 `http://192.168.x.x:8089`）；
3. 点击浏览器菜单选择 **「添加到主屏幕」** 或 **「安装应用」**；
4. 手机桌面上生成 **肘边备急 App 图标**，支持断网离线、全屏沉浸式运行！

### 途径 C：编译为独立 Android 原生 APK
原生封装工程位于 `android/` 目录（纯 WebView 外壳，无第三方依赖，包体极小）：
1. 用 Android Studio 打开 `android/` 目录，或在已装 Gradle 8.2 + JDK 17 的环境下进入该目录；
2. 首次可执行 `gradle wrapper` 生成 wrapper 脚本（本仓库已提供 `gradle/wrapper/gradle-wrapper.properties`）；
3. 执行 `gradlew assembleRelease`，产物在 `android/app/build/outputs/apk/release/app-release.apk`；
4. 支持 Android 8.0（minSdk 24）至 Android 15（targetSdk 34）。

> 应用图标已按 5 种密度生成到 `res/mipmap-*`；如需换图标，改 `tools/make_icons.py` 里的配色/形状后重跑即可。

## 📱 移动端适配说明
- **页头品牌区**：主标题只放产品名「肘边备急」（17px 加粗），副标题控制在 10 字内（「口腔医保精算 · 红线拦截」）——
  360px 最窄视口实测两行都不会被省略号截断（拼成一行会被截）。
- **底部七页签导航**：开单 / 精算 / 风控 / **助手** / 文书 / 病历 / 方案，避免长页面无限滚动；风控、助手、文书页签带数量角标。360px 最窄安卓视口实测 7 个页签仍全部落在视口内。
- **常驻结算条**：屏幕底部实时显示「统筹支付 / 患者实付 / 合规状态」，开单时无需来回切换即可看到金额变化。
- **卡片式处方清单**：替代横向表格，彻底消除手机端横向滚动。
- **税率矩阵同样卡片化**：7 类收入 × 6 档税率以「类别卡片 + 税率筹码」呈现，不用 `min-width` 固定的横向表格，手机端不产生内层横向滚动。
- **卡片可点两处**：点卡片主体看**项目详情**，点右侧「＋ 加入」直接入处方，避免误触。
- **触控尺寸**：所有按钮、输入框高度 ≥ 36–44px，符合移动端可点击性规范。
- **输入防放大**：表单字号 ≥ 16px，避免 iOS 聚焦时页面被强制缩放。
- **安全区适配**：适配刘海屏 / 灵动岛 / 安卓手势条（`env(safe-area-inset-*)`）。
- **状态持久化**：城市、参保类别、处方、税务参数、合规自查勾选自动本地保存，刷新或重开不丢数据。
- **导出测算单**：支持一键导出 txt 测算单，内嵌 WebView 不支持下载时自动降级为弹层全文。
